# DPGSA UoN public site: registration and homepage hero

## Implementation

Continue the existing React, TypeScript and Vite static website in the supplied GitHub repository. Keep the six existing public pages and registration information. On the homepage only, position the shared navigation transparently above a full-width hero carousel. Use two original landscape image assets generated for the carousel, with slide-specific truthful DPGSA copy, registration calls to action, previous/next and direct slide controls, an explicit persistent pause/resume control, and automatic advancement. Keep the hero in the normal main content flow and keep all text as accessible, selectable HTML rather than text baked into images.

Use a small homepage hero component that owns carousel state and automatically advances at a calm interval. Reset the timer on every slide change. Pause during hover, when the document is hidden, and whenever the visitor requests reduced motion. When keyboard focus enters the carousel, stop automatic rotation and keep it stopped until the visitor explicitly chooses resume; never surprise keyboard users by restarting motion as soon as focus leaves. Allow manual controls and a visible slide-position indicator. Keep slide transitions limited to composited opacity/transform properties, use a smooth custom ease, and provide responsive overlays and text-safe image crops on mobile. The non-home routes retain their existing opaque header and utility bar.

The site remains runnable with the existing npm script `npm run dev:static`; use npm’s Vite-based static build, type-check, and test scripts where needed. The repository structure remains `client/src/pages/` for public routes, `client/src/components/` for shared layout and home hero components, `client/src/routes.tsx` for page registration, `client/public/images/` for assets, and `scripts/prerender.mjs` for static page output. No new packages, backend, storage or CSS framework are needed.

## Design

Use the existing DPGSA/University blue, white and warm accent palette, with the hero photograph extending behind the transparent navigation. The carousel is a cinematic editorial introduction: two coordinated 16:9 illustrative photographs for student privacy-policy learning and campus community, each with dark left-side space for the headline, alternating with a gentle crossfade and subtle pan. Keep the association logo and header links legible on the image. Provide keyboard-accessible controls, including the explicit pause/resume toggle, and do not autoplay under a reduced-motion preference. Preserve all lower homepage content and the existing membership page.
